itemanim.2da

This file lists the character animation sequence to be played when an item ability is used.
In BG2EE we have:
2DA V1.0
-1
           SEQUENCE   
POTN00     -1         
FIRESEED   8
The first column is the item reference.
The second column is the animation sequence to play (from seq.ids).
{% capture note %} The EE engine reads sequence entries from this file as their raw character values rather than converting them to the numbers they represent.

For example: To correctly insert `SEQ_SHOOT` into the file, you must use the raw byte value 0x8 rather than the character '8'. {% endcapture %} {% include bug.html %}
